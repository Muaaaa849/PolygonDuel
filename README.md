# POLYGON DUEL

**形を読め。止まるか、動くか。** — 見下ろし型 1 vs 1 “形を読む” 対戦アクション。
スマホ2台で P2P 対戦。遠くの人とは **リンクを送るだけ**、近くの人とは **QRを読み合うだけ**（サーバー0台・費用0円）。GitHub Pages で配信します。

| 形 | 状態 | 見た相手がとるべき対処 |
|---|---|---|
| 円＋棒 | 攻撃（ガード可） | **止まってガード** |
| 三角（縁が点滅） | ガードブレイク | **動く・ステップで避ける** |
| 六角 | ガード中（ゲージで縮む） | **三角(GB)で崩せ** |
| 矢印 | ステップ | 硬直を狩れ |
| 星つき四角 | スタン | フルコンボ |
| 五角 | 回復・バフ | 殴りに行け |
| 四角 | 通常・移動中 | 何でもできる |

## 遊ぶ

- **チュートリアル**（約90秒・5レッスン）→ CPU戦（3段階）→ 2台で対戦、の順がおすすめ。
- **リンクで対戦（遠くの人と）**：「リンクで部屋を作る」→ リンクをLINE・Discordなどで送る → 相手が開けば接続（ルームコード入力でも可）。
  接続情報の受け渡しにだけ公開のPeerJSシグナリングサーバーを使い、対戦は端末どうしの直接通信です。
- **QRで対戦（近くの人と）**：片方が「QRで部屋を作る」→ もう片方が「QRで部屋に入る」でQRを読む → 表示されたQRを最初の人が読む → 接続。
  テザリング／同じWi-Fiなら端末どうしが直結（RTT数ms）。カメラが使えない時はコードの貼り付けでも接続できます。
  ホストのQRはURLなので、標準カメラアプリで読んでもそのまま参加画面が開きます。
- **トレーニング**：ダミー7種（棒立ち／無限ガード／ヒット後ガード／攻撃ブンブン／GB連発／ステップ連発／CPU）、
  フレームメーター、有利フレーム表示、判定表示、0〜6Fの遅延シミュレーション、コスト無限。
- PCではキーボード（WASD/矢印・J/K/L・Space）とゲームパッド、1台2人対戦にも対応。

## 開発

```bash
npm install
npm run dev          # http://localhost:5173
npm run dev:https    # LAN内のスマホで試す時（カメラはHTTPSが必須）
npm test             # フレーム規約・コンボ・ロールバック・決定論・CPU・処理時間のテスト
npm run build        # dist/ に出力（Service Worker付き）
node tools/perf-bench.mjs fight|firstuse|resize   # 性能の計測（devサーバーが必要。CLAUDE.md §12）
```

### 公開（GitHub Pages）

`.github/workflows/deploy.yml` が push のたびに型チェック・テスト・ビルドを実行し、デフォルトブランチでは Pages へ自動公開します。
初回のみリポジトリの **Settings → Pages → Build and deployment → Source を「GitHub Actions」** にしてください。

## 構成（計画書 第11章）

```
src/
  core/        決定論シミュレーション（固定小数点 1u=1000・1024分割角・焼き込み三角関数表・状態機械）
  data/        キャラ定義（純データ）と共通数値 system.ts
  net/         QRシグナリング（SDP→約120文字）、WebRTC、ロールバック
  input/       フローティングスティック・形アイコンボタン・キーボード/ゲームパッド
  render/      PixiJS：形モーフ、矢印→棒、ガードの震え、軌跡、火花、破片、衝撃波、色収差、ブルーム
  audio/       WebAudio合成の効果音・振動
  ai/          CPU（形を見てから反応。反応速度と正答率が難易度）とトレモ用ダミー
  app/         画面（タイトル／キャラ選択／オンライン／対戦／リザルト／チュートリアル／設定）
tests/         規約テスト・コンボ表・ロールバック・決定論・QR・CPUソーク
tools/         三角関数表とアイコンの生成、スクリーンショット／2台接続のE2Eスクリプト
```

キャラ追加は `data/characters/` に1ファイル足して `index.ts` に登録するだけ。`npm test` が第6章の規約を全キャラに自動で適用するので、規約を破る数値はCIで落ちます。

## テストで保証していること

- **第6章の規約を実際のシミュレーションで検証**（ボットに操作させて結果を確認）：C1〜C8、ヒット確認猶予、2段目止めで防御側+3F、GC関連（近距離）、GC同士のループ無し、長槍の先端にGCが届かないこと、ジャスト攻撃の確定、ブレイズS1のチェーン初期化、バスティオンの当て身キャンセル30〜37F、ゼファーのダウン追撃 など。
- **第7章のコンボダメージ表**（13ルート）が1の位まで一致。
- **ロールバック**：遅延0〜6F・パケットロス最大10%・順序入れ替えの擬似ネットワークで、両端末の状態ハッシュが一致し、巻き戻し後の状態が一直線に実行した結果と同一。
- **決定論**：同じ入力列→同じハッシュ、状態は32bit整数のみ、スナップショットの復元が無損失。
- 実ブラウザ2つでのQR（貼り付け）接続→対戦も `tools/online-test.mjs` で確認（直結・チェックサム照合でずれ0件）。

## 計画書から補完・調整した点

計画書に記載がない部分は、テーマ（形＝正しい対処）とプレイヤー視点から補完しました。

| 項目 | 内容 | 理由 |
|---|---|---|
| 間合いとGC | GCの踏み込みは各キャラの1段目と同じ。先端ギリギリで当てられた攻撃は、ガードしても押し戻しでGCが届かないことがある | 距離感を制した側に明確なメリットを残すため（ゼファーの長槍の先端当てと同じ思想を全キャラに） |
| スキルのキャンセル受付 | 各段の「ヒット時の次段受付」と同じ範囲（ヒット/ガード問わず） | 計画書の図6-5（S1は38Fに刺さる）と当て身30〜37Fの両方と一致する唯一の解釈 |
| 空振り時 | 次段・スキルへ繋げない | 「空振りの隙」「ジャスト攻撃が確定」を成立させるため |
| ステップ硬直 | 11F目から攻撃でキャンセル可、ガードは不可 | 「硬直8Fはふつうに殴られる」「矢印＝硬直を狩れ」を守るため |
| チェーンの向き | 2・3段目は前の段の向きを維持（＋最初8Fの追尾） | スマホで親指がズレても事故らないように |
| 入力バッファ | 押下を6F保持 | 受付開始前に押しても最速で出る。受付範囲そのものは変えない |
| 形の確認 | 1ラウンド目の前に3秒表示（設定でオフ可） | 計画書13章 |
| ファントムの幻影 | 攻撃が幻影に触れると消えてコスト1が戻る。本体が攻撃・ステップ・被弾すると解ける。相手側にはコストも支払い前の値を見せる | 釣った報酬で「幻影→GB」に届くように。本体が見えないまま殴れると理不尽なので行動したら姿を現す |
| エイムの二重丸 | 内側の円はタップ・長押しとも自動照準、外側で自由エイム、遠くで離すとキャンセル | タップで一瞬違う方向が光る煩わしさを無くし、狙う時は本当に自由に |
| 壁ダメージ | 30＋勢いで最大+30、補正あり、1コンボ2回まで。ガードの押し戻しでは発生しない | 端に追い込む意味を作りつつ、壁ループで一方的にならないように |
| ジャスト回避 | 0.6秒のスロー中にATKで瞬間移動JA（相手の1.3u手前）。移動しても相手は攻撃の硬直中なので確定 | 外側に避けても追撃できるように。成功の爽快感を最大に |
| エイムの発動タイミング | 自由状態・ステップ中だけ「離して発動」。ガード硬直中（GC）・チェーン・キャンセルは押した瞬間に発動 | エイムの自由度と、GCやコンボの入力受付を両立するため |
| エイムした技 | 向き固定・ホーミングなし。リーチ段階で踏み込み／突進が40〜100% | 偏差攻撃を成立させるため。自動照準（タップ）は従来どおり追尾 |
| 描画の回数 | シムが進んだフレームだけ描く（90／120Hzの画面でも毎秒60回） | 60Hzのゲームなので見た目は同じ。負荷・発熱・電池を減らし、カメラとコマの動きも揃う |
| ポーズ中の画面 | 止める（エフェクトも止まり、再開すると続きから） | 裏で動かす意味がなく、ぼかし付きメニューの負荷も無くなる |
| オンラインの演出 | 巻き戻しで1〜2Fずれて再発行されたヒット等は二重に出さない | 火花・音・ダメージ数字が2回出ると「2回当たった」ように見えるため |
| 発生の速さ（v0.7） | N1の発生15〜18F（約0.25〜0.3秒）、GBは21〜24F | 人間の反応＋通信遅延で「見てからのガードが間に合うか間に合わないか」。見てから守れると、先に振る側だけが損をする |
| 空振りの硬直 | 通常技が何にも触れなければ、硬直は60%で終わる。ジャスト回避された技は短くならない | 攻撃を置いておく意味を作り、待ちが一方的に有利にならないように。JAの確定は残す |
| ステップ→攻撃 | ステップ3F目から攻撃・スキル。ステップの残りの移動が技に乗る | 1〜2F目のジャスト回避は必ず残す。ステップを見たらガードが必要になり、ステップ→GBの択が生まれる |
| ガードゲージ | 1.5秒（バスティオン1.75秒）。攻撃をガードするたびに満タン | 見合って固まる時間を減らす。ガードできている攻撃のせいで割れる理不尽は起こさない |
| リポスト | 成立で反撃70＋よろけ＋引き寄せ→2段目→3段目（計210）、コスト返却 | コストを払って読み勝ったのに、ガード→GCより得が少なかったため |
| レイの射撃モード（v0.8） | 被弾しても維持（ラウンドごとに解除）。モード中の1〜3段目は出ないが、GC・JAは近接のまま | 「撃つと決めた時だけ撃つ」を切替コストで表現。ガードした側が有利という原則は崩さない |
| 弾と弾どうし・幻影 | レイ同士の弾はすり抜ける。弾が幻影に触れると幻影は消える（釣られた扱い） | ミラーを単純に保つ。幻影は「攻撃が触れたら消える」約束に合わせた |
| フィールドの感電後 | よろけ30Fの間も弾は当たる（コンボ補正の外の単発） | レイの追い詰めの報酬。ただし30Fなので大きなコンボにはならない |
| 弾ジャストの判定 | ステップの移動中（1〜10F）に弾が胴体に触れた時だけ。横に外れた回避・硬直中の被弾は対象外。成立で射手は弾切れ硬直（JAの受付の間＋発生まで）、画面の弾は全部消える | 「飛び込めば報われる」を確実にしつつ、ただ避けただけでは反撃権を得ない |
| ガード時の壁 | 弾・ブラストのガードで場外に触れると30（補正なし）。コンボの壁2回の上限とは別。1回の押し戻しにつき1回 | 壁際では食らった方が安い（20＜30）、という場所の読み合いを作る |
| ヴォルトの突進 | ステップの3F目からだけ。持続中はすり抜け、終わりに重なっていたら前へ押し出す。有利Fはどの持続Fで当たっても同じ（+3／+2） | 突進の当たり方で有利が変わると読み合いが不安定になるため |
| 突進の必敗 | 発生前・持続中に攻撃判定（弾も）が触れたら突進だけが負ける。その攻撃は×1.5（そこから続く2・3段目も）、GBでも怯む（30F）。停止+4F | 「ステップを見たら置く」を最大の対策にする。相打ちにしない |
| ヴォルトの突進も弾ジャスト扱いにしない | 突進は攻撃なので、弾が触れたら負け（×1.5） | 設計書の案どおり |
| ターンバックの発生 | 突進の持続後の受付（13〜20F）から発生30F（全体58F） | 設計書の数値（発生22F）だと規約R10「GC＋2F ≤ ターンバック」を満たせないため、規約を優先した |
| CPUの弾への反応 | 射撃の予兆を見てから反応時間の後にだけ反応。飛び込み（ステップ）の成功率は通常の反応の半分 | 1発目の奇襲を成立させる。CPUが弾を完璧に抜けるとレイが何もできない |

## UI/UX（計画書からの改善）

- **ボタンのアイコン＝その技で自分がなる形**（攻撃＝円、ブレイクファング＝三角、リポスト＝六角…）。操作と「形の言語」が一致し、コスト不足は暗転、使える時は縁が光る。
- **フローティングスティック**：左半分のどこに触れてもスティック。離すとノブが六角に変わり「離す＝ガード」を常に示す。中央通過時の2Fヒステリシス（計画書4章）も実装。
- **足元の資源表示**：各キャラの足元にコスト◆とステップ残数。相手のコスト（＝GBが来るか）を画面中央から目を離さずに読める。
- **ダイナミックカメラ**：近づくと最大1.28倍に寄って形を大きく見せる（設定でオフ）。
- **形は2F目で判別可能**：モーフの初速を大きく（バネ k=0.6, d=0.7 → 約4Fで収束・約13%オーバーシュート）。三角は縁が明滅し、予兆音も鳴る（音でも読める）。
- **攻撃の予兆**：矢印が発生Fに合わせてリーチまで伸び、持続中は棒になる。
- **読みやすい結果画面**：与ダメ・最大コンボ・GC・ジャスト・クラッシュ・ガード回数と、内容に応じたワンポイント助言。
- **トレモの有利フレーム表示**（+3Fなど）とフレームメーター。
- **接続画面**：ステップ表示・経路（直結/経由/中継）とRTTのバッジ・テザリング推奨・カメラ許可の理由を1行で説明・コード貼り付けとリンク共有の予備手段。
- アクセシビリティ：フラッシュ抑制、左右入れ替え、ボタンサイズ、振動、音量。縦持ち時は回転を促す表示。

## v0.2 の変更（爽快感アップ）

- **コマ約1.45倍・カメラ寄せ**：フィールドを16×9u → 11×6.2uに縮めて拡大表示（リーチ・踏み込み・ステップなどの距離関係はそのまま）。近づくと最大1.4倍まで寄る。
- **横振り攻撃**：通常技・GC・JAは前方70°の扇。1段目はキャラごとに右から（ブレイズ・バスティオン）／左から（ゼファー）、2段目は逆から、3段目は一回転。
  持続1F目で正面まで届くので、計画書のフレーム規約（C1〜C8）はそのまま成立（テストで確認）。予兆中は振る範囲の扇が浮かび上がる。
  スキルの突き（ゲイルピアス等）は突きのまま＝横に避けられる。
- **被弾側もコスト回復**：攻撃側+0.5（1コンボ最大1.5）に対し、被弾側は+0.25（最大0.75）。
- **エフェクト**：`tools/fx/gen_fx.py`（NumPy＋OpenCV＋Pillow）で数式から焼いた透過WebPスプライト21種。
  汎用（斬撃・回転斬り・ヒット・六角ハニカムのガード・3段目の攻撃側リップル・ジャスト・KO・土煙）はキャラ色で着色、
  スキル固有（フレアの炎・ブレイクファングの牙・ゲイルの風槍・ブリーズの癒しの風・リポストの反射・シールドバッシュの衝撃壁）は色ごと焼いている。
  状態も表示：GB予兆の警告オーラ、スタンの渦、当て身中の六角シールド、ジャスト攻撃受付中のシアンの収束、バフ中の風。
  透過動画はiOSで透過が安定しないため、スプライトシート方式にした。起動後にバックグラウンドで読み込み、未読込でも手続き的エフェクトで遊べる。

## v0.3 の変更

- **ステージ1.5倍・追従カメラ**：コマの大きさはそのまま、16.5×9.3u の広いステージをカメラが追いかける。移動速度は約10%ダウン。
- **ドラッグでエイム**：攻撃・スキルボタンを押したままドラッグで方向と突進距離を指定、離して発動（範囲が光る）。下がりながら攻撃・偏差攻撃ができる。
- **技の詳細**：キャラ選択でスキルをタップすると、実速度のプレビューとフレーム・相手の対処が見られる。

- **スマホで画面が真っ暗になる問題を修正**：エフェクト画像をスマホ用に半解像度化（GPUメモリ 154MB → 38MB）。

## v0.4 の変更

- **エイムの二重丸**：内側＝自動照準（タップ・長押し）、外側へドラッグ＝自由に狙う（補正なし）。
- **壁ダメージ**：場外に叩きつけると追加ダメージ。場外の線が波打つ。
- **ジャスト回避**：スローモーション＋モノクロの演出。攻撃を押すと相手の目の前へ瞬間移動して必ず当たるジャスト攻撃。
- **ボタン配置を自由に**：設定から位置と大きさを変更。設定ファイルの書き出し・読み込み。

- キャラ追加の手引き：`characterSetting.md`。

## v0.5 の変更

- **新キャラ「ファントム」**（紫・幻惑トリック）：S1ゴーストで幻影を出すと、相手の画面では幻影が本物に見え、本物は見えなくなる。S2はガードブレイク「ソウルリッパー」。
  幻影でガードを誘って崩す／幻影読みの相手には本物で殴る、の読み合い。
- キャラ選択は4キャラ用のレイアウトに。

## v0.6 の変更（軽量化・ラグ対策）

見た目と手触りはそのままで、スマホとオンラインを軽くしました。今後のルールは CLAUDE.md §12。

- **最初のヒットで止まらない**：エフェクトの準備（シェーダー作成・画像のGPU転送）をタイトル画面のうちに済ませる。以前は最初の3段目・ジャスト回避・KOの瞬間に一瞬止まっていた。
- **高リフレッシュレートのスマホで軽く**：描画は毎秒60回まで。60Hzでもフレームの刻みを揃えた。ポーズ中は画面を止める。
- **画質の自動調整**がコマ落ちの回数を見るようになった。
- **オンライン**：巻き戻しで演出が二重に出ることがあったのを修正。送信のたびのメモリ確保を無くした。
- **起動が軽く**：QR読み取りは使う時だけ読み込む（起動時のJSが約2割減）。
- **バグ修正**：対戦中に画面の向きやブラウザのバーが変わると、画面が固まる・真っ黒になることがあった（描画ライブラリの不具合の回避）。

## v0.7 の変更（テンポ）

- **攻撃が速くなった**：1段目は15〜18F。見てから守るのはギリギリなので、読みで止まる・置く・動く。
- **1→2→3が速い**：ガード後にGCで勝てる差も小さくなった。
- **空振りの隙が小さい**：攻撃を置いておける。
- **ステップからそのまま攻撃**：ステップの勢いに乗った一撃。ステップ→GBも。
- **ガードは1.5秒**：ただし攻撃をガードするたびに満タンに戻る。何もせず固まっていると割れる。
- **リポストが強くなった**：成立すると2段目→3段目まで入り、コストも戻る。

## v0.8 の変更（新キャラ2体）

- **レイ（黄）**：射撃モード（S1）で菱形の弾を最大3発。弾は**ステップで飛び込む**のが正解（弾ジャスト→射手は弾切れ→瞬間移動JA）。
  ガードすると0ダメージだが大きく押し戻され、**壁際でガードすると30ずつ**。2段目からS1で切替ブラスト（相手を吹き飛ばして射撃モードへ）。
  S2のスタティックフィールドの中では、ステップすると感電する。
- **ヴォルト（水色）**：ステップが3つ。ステップ中だけ出せるダッシュスラストで相手をすり抜けて背後へ（ガードされても有利）。
  ただし**突進中に攻撃が触れると必ず負けて×1.5**。突進の直後にターンバック（三角）で背後からガードを崩す。
- 新しい形「**菱形**＝射撃・弾 → ステップで弾に飛び込め」。
- 固有エフェクト：散弾（ブラスト）、感電の稲妻、振り返りの三角、水色の予兆。弾・電場・突進の残像と光の線・照準線は描画で。
- 固有の音：弾の「チュン」、空撃ちの「カチッ」、感電、突進、突進が負けた時の一撃。
- キャラ選択は6人（ステップの数も表示）、技詳細の実演も新しい技に対応。CPUも新キャラを使い、全キャラが弾とヴォルトの突進に対応する。
